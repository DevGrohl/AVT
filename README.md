# AVT

AVT is an Architecture Visualizer Tool for helping developers understand unfamiliar projects through Execution Flow Graphs.

See:

- `CONTEXT.md` for project language.
- `docs/restart-plan.md` for the restart plan.
- `docs/adr/` for architecture decisions.

## Monorepo layout

- `packages/analyzer` — Python analyzer package and `avt` CLI.
- `apps/viewer` — future static web viewer.
- `spikes/visualization-libraries` — graph library comparison spikes.
